# Theme

- A theme toggle or theme switch: add `<script src="/vendor/clanker-ui/clanker-ui-theme.min.js"></script>` (classic script, no `type`, no `defer`) after the stylesheets and before the modules. It stops a flash of the wrong theme. With the readable set, use `clanker-ui-theme.js`.
- Light and dark follow the system. A toggle button: `<button type="button" data-slot="button" data-variant="ghost" data-size="icon" data-theme-set="toggle" aria-label="Dark mode"><svg data-lucide="contrast"></svg></button>`. From code: `theme.set("light" | "dark" | "system")`. More: [components/theme.md](components/theme.md).
- Brand colors: override the shadcn tokens in `app.css` (`--primary`, `--radius`, ...). Light values on `:root`, dark values on `[data-theme="dark"]` and in `@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) { ... } }`. Unlayered app CSS wins over the kit layers. Override tokens, not properties, so hover and dark states stay. With Tailwind or other layered CSS, or to override a kit `!important` rule, read [Override the kit](https://github.com/bl4ko/clanker-ui#override-the-kit).
- Color schemes: load `clanker-ui-themes.css` and set `data-scheme` on `<html>`: one base scheme, then optional parts, separated by spaces (`data-scheme="zinc blue radius-large"`). Accents work on the shadcn base schemes.
  - shadcn base schemes: `neutral`, `zinc`, `stone`, `gray`, `slate`, `mauve`, `olive`, `mist`, `taupe`.
  - Editor schemes (own accent, no extra accent): `tokyonight-night`, `tokyonight-storm`, `tokyonight-moon`, `catppuccin-mocha`, `catppuccin-macchiato`, `catppuccin-frappe`, `gruvbox`, `nord` (dark only), `dracula`, `rose-pine`, `rose-pine-moon`, `solarized`, `one`, `kanagawa-wave`, `kanagawa-dragon`, `everforest`, `github`.
  - Accents: `amber`, `blue`, `cyan`, `emerald`, `fuchsia`, `green`, `indigo`, `lime`, `orange`, `pink`, `purple`, `red`, `rose`, `sky`, `teal`, `violet`, `yellow`.
  - Options: `radius-none`, `radius-small`, `radius-medium`, `radius-large`, `menu-bold`.
  - From code: `theme.setScheme("zinc blue")`; `theme.schemes` lists `{ value, label, group }` with `group` `shadcn`, `editor`, or `accent`. A `<select data-theme-picker>` (base) and `<select data-theme-picker="accent">` fill themselves.
- Chart colors: `--chart-1`…`--chart-8` are 8 distinct hues (validated for light and dark). Override them in `app.css` like the other tokens, light and dark. A shadcn base scheme (`data-scheme="neutral"`, `zinc`, ...) sets shadcn's gray `--chart-1`…`--chart-5`; add `clanker-ui-a11y.css` or override them to keep hues. Good and bad series in charts: `--chart-good`, `--chart-bad`. Status marks (bars, dots, meters, uptime strips): `--success-fill`, `--warning-fill`, `--error-fill`, `--info-fill` (same hue in light and dark). `--success-text` and the other `-text` tokens are for text, `-bg` and `-border` for badges and alerts.
